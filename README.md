# JAI SHANTOSHI MAA — Newspaper Distribution & Billing (Angular 21)

Modern Angular 21 application built with **Signals**, **Zoneless Change Detection**, automatic **Current Month Billing Cycle**, **Persistent LocalStorage**, **Weekend/Schedule-Aware Pricing**, **CSV/Excel Import & Export**, and **Individual WhatsApp/Print Invoices**.

## Quick Start
```bash
npm install
npm start
```
